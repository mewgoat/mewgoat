## Welcome to my corner of GitHub — I'm mewgoat 👋

Small tools, sharp edges, no drama.

I'm a frontend developer who builds web apps with TypeScript, React, and Next.js. Most of my work revolves around design systems, component libraries, and making sure things are fast and accessible out of the box. I spend a lot of time in TailwindCSS and Vite, usually chasing better build times or shaving kilobytes off bundles.

#### About me

- 🔭 Building a lightweight component library with accessible defaults.
- currently deep in design systems
- usually building small tools nobody asked for
- happier in a terminal than in an IDE
